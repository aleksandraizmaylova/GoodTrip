# GoodTrip

## Технические решения

|                                         Что решали                                         |                                                                                   Какие варианты рассматривали                                                                                    |                                                                                                               Что выбрали и почему                                                                                                                |
|:------------------------------------------------------------------------------------------:|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------:|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------:|
|                                   Как показывать карту?                                    |                                                   Вставить на фон картинку; API (Яндекс карты/ Google Maps/ Wikimapia); Конструктор карт Яндекс                                                   |                                                              Решили использовать API Яндекс карт, так как бесплатный тариф полностью закрывал наши потребности и был наиболее удобен                                                              |
|                        Как хранить статусы достопримечательностей?                         |                                                                                        localStorage; в БД                                                                                         |                                                                               Выбрали БД, чтобы поддерживать на сервере актуальную информацию для выдачи достижений                                                                               |
|     Как выдавать пользователям достижения и поддерживать актуальную информацию о них?      | Перепроверять все условия для выполнения достижений каждый раз, когда пользователь заходит на страницу с достижениями; Завести отдельную таблицу для достижений и выдавать их с помощью триггеров | Выбрали отдельную таблицу с триггерами, так как информация о выполнении некоторых достижений нигде больше не хранилась (например достижения “Не сегодня” или “Знаток”), и проще делать запрос к одной таблице, чем каждый раз проверять несколько |
|                          Как организовать связь с пользователями?                          |                                               Ссылка на гугл-форму; Ссылка на соцсеть; Вставить номер телефона одного из участников команды на сайт                                               |                                     Объединили варианты ссылок на гугл форму и соцсеть: Для того чтобы предлагать достопримечательности отлично подходит гугл форма, а для сбора обратной связи ссылка на тг                                      |
| Где взять картинки/иконки для достижений? (не совсем техническое, но решение было сложным) |                                 Найти бесплатные иконки в одном стиле; Нагенерировать картинки в нейросети; Нарисовать самим; Подобрать подходящие по смыслу мемы                                 |                                                                Решили подобрать мемы, так как иконки подобрать было сложнее, рисовать тем более, а генерировать не поднялась рука                                                                 |
